Step 1: Scan Project Folder
────────────────────────────
  ┌─────────────────┐
  │ Project Folder  │
  └────────┬────────┘
           │
           ├── Architectural Plans.pdf (50 pages)
           ├── Specifications.pdf (200 pages)
           ├── Door Schedule.pdf (2 pages)
           └── Addendum 01.pdf

Step 2: Analyze Each PDF
─────────────────────────
  For each PDF:
    1. Check image resolution (DPI)
    2. Extract text content
    3. Look for sheet numbers (A101, S200, etc.)
    4. Classify document type

  Classification Logic:
    ┌──────────────┬──────────────────────────────────┐
    │ High DPI     │ → Drawing                        │
    │ Sheet #s     │ → Drawing                        │
    │ "spec" name  │ → Spec                           │
    │ "addend"     │ → Addendum                       │
    │ "schedule"   │ → Schedule                       │
    └──────────────┴──────────────────────────────────┘

  Results:
    ┌────────────────────────────────────────────┐
    │ Architectural Plans.pdf  → DRAWING         │
    │ Specifications.pdf       → SPEC            │
    │ Door Schedule.pdf        → SCHEDULE        │
    │ Addendum 01.pdf          → ADDENDUM        │
    └────────────────────────────────────────────┘

Step 3: Organize Files (NEW!)
──────────────────────────────
  Create folder structure:
    Extracted-Data/Organized/
      ├── Specs/
      ├── Drawings/
      ├── Schedules/
      └── Addenda/

  For each document:
    ┌──────────────────────────────────────────────────────┐
    │ SPEC/SCHEDULE/ADDENDUM                               │
    │   → Copy entire file to appropriate folder           │
    └──────────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────────┐
    │ DRAWING                                              │
    │   → Split into individual sheets                     │
    │   → Extract sheet number from each page              │
    │   → Extract sheet title from each page               │
    │   → Save as: "A101 - Floor Plan.pdf"                 │
    └──────────────────────────────────────────────────────┘

Step 4: Drawing Sheet Splitting Detail
───────────────────────────────────────
  Architectural Plans.pdf (50 pages)
         │
         ├─ Page 1  → Extract sheet info → A101 - Floor Plan.pdf
         ├─ Page 2  → Extract sheet info → A102 - Floor Plan.pdf
         ├─ Page 3  → Extract sheet info → A200 - Exterior Elevations.pdf
         ├─ Page 4  → Extract sheet info → A201 - Exterior Elevations.pdf
         ├─ Page 5  → Extract sheet info → A300 - Building Sections.pdf
         └─ ... (continues for all 50 pages)

  Sheet Info Extraction:
    ┌─────────────────────────────────────────────────────┐
    │ From page text:                                     │
    │   - Sheet number: A101, A2.1, S200, etc.            │
    │   - Sheet title: "FLOOR PLAN", "ELEVATIONS", etc.   │
    │                                                     │
    │ Fallback if not found:                              │
    │   - Sheet number: "Sheet-001", "Sheet-002", ...     │
    │   - Title from prefix: A1→Floor Plan, A2→Elevations │
    └─────────────────────────────────────────────────────┘

Step 5: Database Tracking
──────────────────────────
  For each organized file:
    ┌───────────────────────────────────────────────────────┐
    │ INSERT INTO organized_files                           │
    │   original_path:   "Architectural Plans.pdf"          │
    │   organized_path:  "Organized/Drawings/A101...pdf"    │
    │   doc_type:        "drawing"                          │
    │   sheet_number:    "A101"                             │
    │   sheet_title:     "Floor Plan"                       │
    │   page_number:     1                                  │
    └───────────────────────────────────────────────────────┘
